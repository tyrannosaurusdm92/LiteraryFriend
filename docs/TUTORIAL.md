# LiteraryFriend Tutorial — Complete Feature Guide

## 1. Sign in, sign up, download, or skip login

The first LiteraryFriend screen is intentionally minimal. It shows **Download app**, **Sign in**, **Sign up**, and **Skip login**. No account fields, recovery forms, verification controls, or technical connection details are shown until you choose an action. **Skip login** enters the writing workspace immediately in local mode without creating or signing into an account.

Choose **Sign in** to reveal the email/username and password fields. Choose **Sign up** to reveal display name, username, email, optional backup phone, password, and password-confirmation fields. The fields use normal browser autocomplete names so a browser or password manager can recognize username/email, current password, new password, phone, and one-time-code inputs. Password fields include Show/Hide controls. Google account access appears inside the expanded Sign in or Sign up flow when it is available for the deployment.

**Forgot password** appears only after opening Sign in. Selecting it opens the separate recovery area containing reset-code steps and emergency recovery-code sign-in. Password-reset controls never occupy the initial access screen. Two-factor verification also appears only when an account actually requires a challenge after successful password sign-in.

A signed-in account can use project syncing, backup contacts, optional two-factor verification, recovery codes, signed-in device controls, personal Google Drive storage, online AI services, project exports, and saved backups. Local writing remains usable after Skip login.

## 2. Create projects and project families

Open **Projects** to create a novel, book, series, short story, anthology, screenplay, screen project, comic, audio drama, poetry project, nonfiction work, TTRPG project, video-game narrative, visual novel, MMORPG world, transmedia setting, or another story format.

Use project relationships to connect books inside a series, games inside a franchise, historical stories inside a shared universe, adaptations, and companion projects. The relationship records preserve canon scope so connected projects can share selected story information without contaminating unrelated work.

Switching projects changes the manuscript, notes, outline, characters, world entries, timeline, languages, continuity issues, tasks, art, book editions, searches, and publishing context together.

## 3. Use Home, Search, and Quick Capture

Home summarizes the active project. The top search field searches working material, and signed-in project search can search writing, notes, characters, world entries, timeline events, language data, and issues together. Saved searches keep recurring editorial questions available.

Quick Capture stores an idea, line of dialogue, research question, note, or journal entry without leaving the current workspace.

## 4. Import existing work

Open **Import & Merge** and add DOCX, PDF, TXT, Markdown, HTML, RTF, JSON, CSV/TSV, XML/YAML, images, audio, video, ebooks, and other supported materials.

LiteraryFriend detects the file type, extracts usable text when supported, classifies the material, and routes it into writing, planning, character, worldbuilding, timeline, language, research, artwork, or project-package workflows. Original source files remain preserved when they are imported as attachments.

Signed-in import intake can index source text, register imports, inspect extracted content, and create connected writing records from ingested files.

## 5. Consolidate multiple versions

Select two or more indexed versions and choose **Compare selected versions**. LiteraryFriend identifies a suggested base, duplicate versions, conflicts, unique material, a proposed consolidated text, and related structured updates when available.

Review the comparison before applying it. Applying a connected consolidation creates a reversible snapshot, writes the consolidated master as a new writing document, preserves the source files, and can apply reviewed updates to related canon records in the same operation.

Use **Mass update canon** when a deliberate name or terminology change should propagate through writing, entities, timeline events, plot threads, and world rules.

## 6. Build the manuscript

Open **Manuscript** to create chapters, scenes, and other writing documents. Reorder material, move it inside chapters or sections, edit text, attach files, use read aloud, use dictation where the browser supports it, search and replace, tag scenes, track status, create snapshots, and export individual documents.

Scene metadata can carry POV, status, story date, location, participants, plot threads, revision state, and related project context. Signed-in manuscript intelligence can extract canon and mentions from project writing and save reading position.

## 7. Use Notes & Journal

Notes & Journal keeps working material separate from manuscript prose. Use notes, journal entries, folders, smart folders, tags, pinning, quick capture, search, Recently Deleted, and restore tools. Signed-in notes can also use connected folders, tags, quick capture, search, and recovery.

## 8. Build the outline and plot-thread lifecycle

Open **Outline** to create beats manually or start with a flexible structure scaffold. Beats can store section, beat type, summary, tags, order, and manuscript links.

Signed-in plot threads can move through introduced, seeded, active, escalated, complicated, dormant, resolved, intentionally abandoned, or carried-forward states. Use **Generate outline** for an adaptive project-aware outline when needed.

## 9. Open Story Intelligence

**Story Intelligence** is the project model behind the manuscript. It brings together the fifteen story systems used across LiteraryFriend:

1. Automatic Story Codex
2. Provenance and source evidence
3. Temporal facts with validity ranges
4. Character state tracking
5. Character knowledge and belief
6. World chronology
7. Narrative order
8. Reader-revelation order
9. Plot-thread lifecycle
10. Setup and payoff tracking
11. Causal graph
12. World-rules engine
13. Scene × thread Matrix
14. Character-view evidence reconstruction
15. Evidence-based Issue Center

Use **Refresh from manuscript** after large writing changes. The Story-state debugger can inspect the project or a selected scene/chapter and show facts, knowledge, threads, rules, and entity mentions connected to that scope.

The Scene × thread Matrix shows where tracked plot threads touch manuscript items. Blank stretches are useful visual signals even when no automated warning is raised.

## 10. Track characters, facts, knowledge, and evidence

Open **Characters** to create searchable character profiles with aliases, role, voice, wants, needs, arc, constraints, relationships, description, attributes, and tags.

Connected character tools add temporal story facts, truth status, validity ranges, evidence mentions, and a knowledge ledger. Choose a character and an established story fact, then record whether the character knows, believes, suspects, denies, forgot, or misremembers it. You can attach the knowledge change to a scene, chapter, timeline event, or source character.

Character search can use names, aliases, tags, locations, relationships, and details.

## 11. Build the World Codex and rules

Open **World & Lore** for locations, organizations, factions, species, cultures, objects, artifacts, magic, technology, law, terminology, and other canon.

Connected world rules store a rule domain, statement, conditions, exceptions, status, and source context. Causal links connect story events, writing items, plot threads, and canon entries through relationships such as causes, enables, requires, prevents, motivates, reveals, foreshadows, or pays off.

Use the causal graph to make prerequisites, choices, and consequences explicit rather than relying on memory alone.

## 12. Use the three-clock Timeline

Timeline separates three different questions:

- **World chronology:** when did the event actually happen?
- **Narrative order:** where does the audience encounter it in the manuscript?
- **Reader revelation:** when is the audience allowed to know it?

Connected timeline events can store start/end chronology values, calendar, era, chronology order, narrative order, revelation order, participants, locations, tags, and description. This supports flashbacks, parallel stories, invented calendars, historical eras, mysteries, and transmedia projects without flattening every time concept into one list.

## 13. Use Research and attachments

Research stores books, articles, websites, archives, interviews, images, primary sources, PDFs, imported media, questions, source notes, and citations. Attachments remain associated with the active project and can be added or removed from the connected account when signed in.

## 14. Find plot holes and continuity problems

Open **Plot Holes & Continuity** and run a project scan. Connected checking can detect or track temporal contradictions, state contradictions, possession problems, location conflicts, knowledge problems, memory contradictions, ability drift, world-rule violations, causal holes, motivational holes, dangling threads, setup/payoff problems, reveal-order errors, recurring detail changes, and POV leaks when supported by project evidence.

Each issue remains author-controlled. Available decisions include **Fix**, **Intentional**, **Update Canon**, **False Positive**, **Review Later**, resolve, reopen, and delete. An automatic fix is only applied when an explicit reviewed patch is available.

Use Intentional for deliberate contradictions such as lies, unreliable narration, false prophecy, disguise, myth, time travel, character misunderstanding, or an intentional retcon.

## 15. Run specialized editors

Open **Revision Lab** for local revision metrics, then use the connected editor team for focused analysis. Available specialties include:

- Continuity Editor
- Plot Editor
- Character Editor
- World Editor
- Timeline Editor
- Developmental Editor
- Line Editor
- Copy Editor
- POV Editor
- Series Editor
- Causality Editor
- Setup-Payoff Editor
- Knowledge Editor

Choose the whole project or a specific scene/chapter. Findings can be added to the Issue Center so editorial suggestions stay separate from the manuscript until you decide what to change.

## 16. Use Literary Assistant

Literary Assistant searches the bundled writing/specialist reference material and builds project-aware prompts. Connected AI jobs are tracked separately from editor runs.

AI-assisted work should preserve author control: feedback and generated structures are proposals, while canon-changing decisions remain explicit actions.

## 17. Create constructed languages

Open **Language Lab** to build a language profile, sound system, phonotactics, syllable patterns, pronunciation rules, orthography, writing system, grammar, morphology, syntax, tense/aspect/mood, pronouns, agreement, number systems, naming rules, idioms, registers, dialects, cultural context, and a searchable lexicon.

The local starter builder creates an editable foundation. Connected generation can create a larger coherent language package and starter dictionary. Dictionary entries can store the word, normalized form, definition, pronunciation, part of speech, etymology, forms, notes, and tags. Connected dictionaries can be exported as JSON or text.

## 18. Use Organizer

**Organizer** keeps project administration beside the creative work. Create tasks with status, priority, category, due date, reminder time, tags, and notes. Filter the task list by status or priority, mark work complete, and keep publishing, revision, research, art, and writing tasks scoped to the current project.

When syncing is enabled, supported task records are saved with the project so they can participate in account backups and project exports.

## 19. Build print and interactive books

Open **Book Builder** to save a book project, choose paperback or hardcover trim presets, create editions, synchronize manuscript chapters, apply chapter formatting, request cover dimensions, and create an interactive HTML edition.

Book layout can include margins, gutter, page numbering, running headers, front/back matter, chapter-open styles, title pages, section breaks, typography, paragraph spacing, drop caps, ornamental dividers, page backgrounds, textures, and reusable series styling where supported by the builder.

The manuscript remains the writing source while book editions and chapter formatting remain associated with the same project.

## 20. Create cover art in Art Studio

**Art Studio** is the cover and illustration workspace. It supports cover-size canvases, custom dimensions, portrait/landscape/square formats, guides, safe areas, zoom, rulers, editable layers, transforms, selections, clipboard operations, image import, colors, palettes, shapes, text, textures, effects, and painting.

Painting media include multiple brush types and settings plus pencil, ink, marker, crayon, charcoal, calligraphy, neon, spray, graffiti, pixel tools, eraser, fills, gradients, eyedropper, and blending/effect workflows. Shape tools include geometric and decorative cover elements. Text remains editable on its own layers.

### AI cover-art tool control

Art Studio AI can do more than request a single flattened image. **Build with Studio Tools** asks the assistant for a structured cover plan and executes that plan as editable canvas operations. The plan can create backgrounds; geometric and decorative shapes; editable text and text styling; textures and patterns; paint, pencil, ink, marker, crayon, charcoal, calligraphy, neon, spray, graffiti, pixel and eraser strokes; flood fills; gradients; eyedropper color samples; layer settings; transforms; filters; and layer ordering. Brush-directed passes can control brush programs, size, hardness, softness, opacity, flow, spacing, smoothing, pressure, mirror behavior, and blend mode.

AI can also use the editing operations that normally happen after drawing: select layers, crop image layers non-destructively, cut/copy/paste, duplicate, group and ungroup, align left/center/right/top/middle/bottom, distribute grouped elements horizontally or vertically, move layers to front/back, resize/stretch/skew/rotate/flip, apply text typography settings, use a reusable stamp when one is loaded, and bake supported paint effects such as grayscale, invert, sepia, sharpen, emboss, or edge treatment. These operations remain editable wherever the underlying Studio feature is non-destructive.

**Add Tool Pass** lets AI add another editable design pass to the current cover instead of replacing the whole composition. **Generate Art** can still create a new image concept and insert it as a layer, after which the same crop, layer, transform, selection, clipboard, color, painting, shape, and text tools can refine it.

Keep title, author, series, badges, textures, and illustration elements on separate layers when you want easy revision. Use safe-area guides before final cover export.

## 21. Use Publish Center

Open **Publish** for the final handoff. Export a portable project package, create an interactive HTML web edition from a saved Book Builder project, return to Art Studio for cover work, or create a backup.

A signed-in project can store generated copies in account storage or linked Google Drive when configured. Local mode can export project data and local backups directly to the browser.

## 22. Connect personal Google Drive

Open Account or Settings while signed in and choose the Google Drive controls. Link Drive, choose a project storage folder, and use it for supported project files, artwork, dictionaries, exports, and backups. You can disconnect it later without exposing account-storage details in the creative workspaces.

## 23. Manage recovery, two-factor verification, and devices

Open **Account** to add multiple backup email addresses and phone numbers, send verification codes, remove non-primary recovery contacts, generate one-time recovery codes, change the password, and review signed-in devices.

Optional two-factor verification can use a verified recovery contact. Lost or old devices can be signed out individually or all other sessions can be revoked together.

## 24. Settings, accessibility, and reading

Settings controls appearance, contrast, reduced motion, target size, text scale, line height, reading width, dyslexia-friendly presentation, read-aloud voice and rate, autosave, spellcheck, writing goals, and syncing.

Interactive book reading can use responsive layouts, text sizing, contrast modes, reduced motion, optional page-turn sound, keyboard navigation, and saved reading position where supported.

## 25. Recently Deleted, snapshots, and activity history

Recently Deleted restores supported writing and note records. Revision snapshots preserve pre-change states for consolidation, bulk changes, and other important operations. Account activity history records meaningful project/account actions such as imports, exports, backups, and account events.

## 26. Useful keyboard workflow

Use `Ctrl/Cmd + K` for global search, `Ctrl/Cmd + S` to save the current document, `Ctrl/Cmd + Shift + N` for Quick Capture, `Alt + 1` for Home, `Alt + 2` for Manuscript, `Alt + 3` for Notes & Journal, and `Esc` to exit focus mode or close supported dialogs.

## 27. Docs & Licenses

Docs & Licenses displays the README, this tutorial, and license/attribution information inside LiteraryFriend. Additional audit and source-mapping files remain in `docs/` for redistribution and development review without adding technical implementation details to the normal creative interface.
